Shortform Automation

Privacy PolicyTerms of Service

Shortform Automation is a personal, single-operator tool. It prepares short vertical highlight compilations and uploads them only to the operator's own YouTube channels (and to the operator's own TikTok and Instagram accounts), and only after the operator has approved each video. It is not a public service and has no public sign-up.

This application uses YouTube API Services.
